Bossmode

This binary does not hold the page of bossmode. The route works, but the page is not built in.

To serve the page, build featherweight-bossmode and set workbench.bossmode.dir in fw.yaml, or the variable FW_WORKBENCH_BOSSMODE_DIR, to its dist directory. A build of fw-workbench can also embed the page: copy dist into bossmode/static before go build.
